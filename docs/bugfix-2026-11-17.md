# 2026-11-17 本机运行包修复

本次检查修复了六类问题：

- 会话失效时，旧界面无法顺利退出并重新登录。现在受保护请求返回 401 后清除工作台，回到登录；旧会话延迟返回的错误不会注销新会话。
- 切换资料或核对分组时，延迟、乱序及分页响应可能把旧原文放在新标题下。现在先清除旧证据，并校验请求所属的来源；读取失败会明确显示错误。
- 同一周期的历史报告超过 100 份后，旧报告缺少访问入口。现在按版本游标翻页，界面加载完整报告历史。
- 恢复副本等待输入 RESUME 时，停止按钮无法及时生效。现在等待确认期间持续响应停止，未确认时保持暂停。
- 复制或导入恢复副本中断后，半成品可能被误启动为空工作区。现在创建副本时先设置启动保护，只有恢复和文件校验成功后才解除。
- 两个安装目录并行启动时，另一个实例的就绪响应可能被误认。现在就绪检查同时校验本次启动的随机实例标识，拒绝其他工作区的健康响应。

已有 v0.3 资料时：先运行“备份.cmd”，再用“停止.cmd”正常停止。解压修正版后，将其中的 `app` 文件夹和四个 `.cmd` 文件复制覆盖到原 v0.3 目录，保留原目录的 `data`、`backups` 和 `runtime`。本修复未改变数据库版本或运行库。请勿将 v0.2 的 data 混入 v0.3；全新使用者直接完整解压运行即可。

验收记录位于 `evidence/verification.json`。前端错误与乱序响应测试使用明确标记的故障注入；数据库回归使用独立的 `reconcile_test`。真实模型、其他电脑/干净 Windows、v0.3 Docker 和真实业务试点仍未验证。本次检查不意味着不存在任何潜在缺陷。
